DSB7_Pandas


Проект по обработке, анализу и подготовке данных с использованием Python, Pandas и SQL.

## 📌 О проекте

В рамках проекта изучались:
- загрузка и сохранение данных
- preprocessing
- анализ данных
- агрегации
- оптимизация обработки
- работа с CSV, JSON и SQLite

Проект ориентирован на практику Data Analysis и Data Engineering задач.

---

## 🚀 Реализованный функционал

### 📂 Работа с данными
- загрузка CSV / JSON файлов
- сохранение обработанных данных
- чтение логов и таблиц
- работа с SQLite

---

### 🧹 Data Preprocessing
- очистка данных
- обработка пропусков
- преобразование типов
- подготовка данных для анализа

---

### 📊 Анализ данных
- фильтрация
- сортировка
- группировки
- агрегации
- вычисление статистик

---

### ⚡ Оптимизация
- оптимизация операций Pandas
- ускорение обработки данных
- работа с большими таблицами

---

### 🔗 Enrichment
- объединение данных из разных источников
- merge/join таблиц
- enrichment datasets
